# DroidXAMPP
Panel kontrol Android untuk Apache dan MariaDB yang berjalan di Termux.

## Fitur pada revisi ini
- Dashboard dan navigasi.
- Start/Stop/Status Apache dan MariaDB melalui Termux RUN_COMMAND.
- Menampilkan hasil perintah yang dikembalikan Termux.
- Halaman awal untuk Database, File Manager, Logs, dan Settings.

## Build
Push repository ke GitHub, lalu buka Actions > Build APK. APK release akan tersedia sebagai artifact `DroidXAMPP-apk`.

## Penting
Ini belum merupakan rilis produksi. Database Manager dan File Manager masih berupa halaman awal. Pengujian wajib dilakukan pada perangkat dan versi Termux yang digunakan.
